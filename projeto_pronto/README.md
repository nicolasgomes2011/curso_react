# Minicurso de React – IFRS Rolante

Projeto utilizado durante o **Minicurso de React** do **IFRS Campus Rolante**.

## Tecnologias abordadas

- React
- JavaScript (ES6+)
- JSX
- Componentes
- Props
- Estado (`useState`)
- Eventos
- Renderização condicional
- Listas
- Consumo de APIs com `fetch`

## APIs Externas

Durante o minicurso serão utilizadas as seguintes APIs públicas:

- **Placehold** – https://placehold.co/400
- **HTTP Cat** – https://http.cat/${code}
- **HTTP Dog** – https://http.dog/${code}.jpg
- **HTTP Goats** – https://httpgoats.com/${code}.jpg
